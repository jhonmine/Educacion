# Análisis Tensorial

Tensores, notación de índices y cálculo en coordenadas curvilíneas.

## Temas

1. Notación de índices y convenio de Einstein
2. Transformaciones de coordenadas
3. Tensores covariantes y contravariantes
4. Tensor métrico
5. Derivada covariante y símbolos de Christoffel
6. Tensor de curvatura
