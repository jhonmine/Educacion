# Cálculo Diferencial

Límites, continuidad y derivadas de funciones de una variable, con sus aplicaciones.

## Temas

1. Límites y continuidad
2. Definición de derivada
3. Reglas de derivación y regla de la cadena
4. Derivación implícita y razones de cambio
5. Máximos, mínimos y trazado de curvas
6. Optimización y regla de L'Hôpital
