# Análisis Numérico

Análisis de convergencia, estabilidad y error de los métodos numéricos.

## Temas

1. Análisis de error y condicionamiento
2. Convergencia de métodos iterativos
3. Teoría de la interpolación y la aproximación
4. Cuadratura gaussiana
5. Consistencia, estabilidad y convergencia
6. Diferencias finitas para ecuaciones en derivadas parciales
