# Prompts para IA · Análisis Numérico

Prompts para estudiar el curso con un asistente de inteligencia artificial, como ChatGPT, Claude o Gemini.

Abre [`prompts.md`](prompts.md), copia un prompt, reemplaza lo que está entre corchetes y pégalo en el asistente.

> La IA puede equivocarse, sobre todo en cálculos largos y en demostraciones. Verifica cada resultado con tus notas, el libro o tu profesor. Úsala para estudiar, no para resolver evaluaciones.
