Notebooks y programas en Python para explorar y visualizar los temas del curso.

```
06-codigo/
├── 01_tema.ipynb

└── ...
```

## Cómo ejecutarlos

1. Instala [Python](https://www.python.org/downloads/) 3.10 o superior.
2. Instala las bibliotecas habituales: `pip install numpy matplotlib sympy jupyter`.
3. Abre un notebook con `jupyter notebook`, o ejecuta un programa con `python nombre.py`.

También puedes abrir los notebooks en [Google Colab](https://colab.research.google.com/) sin instalar nada.
