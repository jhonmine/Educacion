# Métodos Numéricos

Algoritmos para resolver problemas matemáticos con el computador.

## Temas

1. Errores y aritmética de punto flotante
2. Solución de ecuaciones no lineales
3. Sistemas de ecuaciones lineales
4. Interpolación
5. Derivación e integración numérica
6. Solución numérica de ecuaciones diferenciales
