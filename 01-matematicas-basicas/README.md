# Matemáticas Básicas

Fundamentos de álgebra, funciones y trigonometría para comenzar la carrera.

## Temas

1. Conjuntos y números reales
2. Expresiones algebraicas y factorización
3. Ecuaciones e inecuaciones
4. Funciones y sus gráficas
5. Funciones exponenciales y logarítmicas
6. Trigonometría
