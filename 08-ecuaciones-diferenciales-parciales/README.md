# Ecuaciones Diferenciales Parciales

Las ecuaciones clásicas de la física matemática y sus métodos de solución.

## Temas

1. Clasificación de ecuaciones de segundo orden
2. Series de Fourier
3. Ecuación del calor
4. Ecuación de onda
5. Ecuación de Laplace
6. Separación de variables y transformada de Fourier
